# كوداك | كتالوج المنتجات المختارة

[فتح الكتالوج](https://hassana176.github.io/codak-products-catalog/)

كتالوج عربي لإدارة المنتجات والموردين والمواسم، وحساب هامش الربح ومقارنة المنتجات. يستضيف GitHub Pages التصميم، ويحفظ Supabase بيانات الكتالوج والوسائط المشتركة.

- المشاهدة متاحة من رابط الموقع. التعديل يتطلب رابط دخول بالبريد الإلكتروني وحسابًا مضافًا إلى قائمة المحررين في قاعدة البيانات.
- الإضافة والتعديل والحذف تظهر للجميع بعد نجاح الحفظ، دون إعادة رفع HTML.
- تصل التحديثات عبر Realtime، مع تحديث احتياطي كل 15 ثانية أثناء فتح الصفحة. ينتظر التحديث إغلاق النموذج المفتوح.
- الحفظ يتحقق من رقم النسخة لمنع استبدال تعديلات أحدث. عند فشل الاتصال يمكن إعادة المحاولة أو تنزيل التعديل.
- الصور والفيديوهات المرفوعة تحفظ في Storage. تُحذف الوسائط التي لم تعد مستخدمة بعد نجاح حفظ الحذف.
- يمكن تنزيل JSON واستيراده بعد تأكيد استبدال النسخة المشتركة. يحتوي JSON على روابط الوسائط السحابية؛ احتفظ أيضًا بملفات الوسائط الأصلية.
- لنقل منتجات النسخة القديمة، افتح الموقع في المتصفح الذي أضفت منه المنتجات، وسجّل الدخول ثم استخدم تنبيه نقل النسخة القديمة. لا تُنقل المسودة القديمة تلقائيًا.

التنفيذ: ملف `index.html` واحد يتضمن التصميم والخط وعميل Supabase JavaScript المثبت على الإصدار 2.105.0. المفتاح الموجود فيه مفتاح نشر عام، وتفرض قاعدة البيانات وStorage صلاحيات RLS. لا يحتوي الموقع على مفتاح secret أو service role.

البيانات الحالية من نسخة HTML التي رفعها صاحب الكتالوج، وتتضمن منتجين وصورتين وفيديو، والأسعار بالدولار الأمريكي. حُفظت الوسائط في Supabase Storage. الأرباح تُحسب من التكاليف المدخلة قبل المصاريف الثابتة.
